# 🎬 TikTok Video Downloader HD (Chrome Extension - Manifest V3)

Extension សម្រាប់ Google Chrome, Microsoft Edge, Brave និង Opera ដើម្បីទាញយកវីដេអូ TikTok កម្រិតច្បាស់ HD គ្មាន Watermark (No-Watermark) និងទាញយកសំឡេង MP3 ដោយចុចតែម្តង (One-Click Download)។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

1. **⚡ ប៊ូតុង Download ផ្ទាល់លើ Video TikTok (On-Page Injected Overlay)**:
   - នៅពេលលោកអ្នកកំពុងមើលវីដេអូលើគេហទំព័រ `tiktok.com` វានឹងបង្ហាញប៊ូតុងអណ្តែតលើវីដេអូនីមួយៗភ្លាមៗ៖
     - ⬇️ **HD No-Watermark** (ទាញយកវីដេអូ HD គ្មានជាប់ Logo)
     - 🎵 **Audio MP3** (ទាញយកតែសំឡេងភ្លេង/ការនិយាយ)
     - 🎬 **BT Dubber** (បញ្ជូនទៅ BT Dubber Studio ដើម្បីបកប្រែជាភាសាខ្មែរ)
2. **📱 Extension Popup ទំនើប**:
   - ចាប់យកវីដេអូនៅលើ Tab ដែលកំពុងបើកដោយស្វ័យប្រវត្តិ។
   - មានប្រអប់ Paste Link ដើម្បីទាញយកវីដេអូពីគ្រប់ Link TikTok (រួមទាំង Short links `vt.tiktok.com`)។
3. **🚀 ដំណើរការលឿន និងទម្ងន់ស្រាល (Manifest V3)**:
   - ប្រើប្រាស់ Chrome Downloads API ផ្ទាល់ ដាក់ឈ្មោះហ្វាយស្អាត និងមានសុវត្ថិភាពខ្ពស់។

## 🛠️ របៀបដំឡើងចូលទៅក្នុង Google Chrome (Installation Guide)

1. **បើក Google Chrome** (ឬ Microsoft Edge / Brave)
2. ចូលទៅកាន់អាសយដ្ឋាន៖ `chrome://extensions/`
3. បើក **`Developer mode`** (នៅជ្រុងខាងស្តាំខាងលើ)
4. ចុចលើប៊ូតុង **`Load unpacked`** (នៅជ្រុងខាងឆ្វេងខាងលើ)
5. ជ្រើសរើស Folder៖
   ```
   d:\bt-dubber\bt-dubber\tiktok-downloader-extension
   ```
6. រួចរាល់! Extension នឹងបង្ហាញនៅលើ Toolbar នៃ Chrome។

- **វិធីទី ១ (ងាយស្រួលបំផុត)**៖ ចូលទៅកាន់ `https://www.tiktok.com` ហើយមើលវីដេអូ លោកអ្នកនឹងឃើញប៊ូតុង `HD No-Watermark` អណ្តែតនៅជ្រុងខាងស្តាំខាងលើនៃវីដេអូ ចុចលើវាដើម្បី Download ភ្លាមៗ។
- **វិធីទី ២**៖ ចុចលើ Icon Extension នៅលើ Toolbar នៃ Chrome ដើម្បី Download វីដេអូក្នុង Tab បច្ចុប្បន្ន ឬ Paste Link វីដេអូ TikTok ចូល។
